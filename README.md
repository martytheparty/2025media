# 2025media
A system to assist in making images and videos available for viewing and download.

Every 4-5 years I build another media visualization system.  I built my first one in 1997 and it was litterally just HTML and JPGs.  

A lot has changed... but the biggest challenges are: 

1. We can capture 1000s and even 10s of 1000s of images/movies in one session.
2. We the files themselves can me huge.
3. Some processes are so much easier and efficient on a local computer that they should be done before FTPing.
4. Some processes are so more convenient when done one the server after FTPing.

After serveral years of buiding these things uploading via the browser is so much less reliable than traditional FTPing that FTP makes more sense.

One thing that I am not sure about is maybe it would make more sense to do all of the processing locally and to build a custom FTP program that uploads data as part of the workflow.

Traditionally I have done things like creating thumbnails on the server...

The advantages to doing everything locally would be that all of the processing code would be on my machine which would probably be a LOT more secure.  The disadvantage would be that I would 100% always have to put the media items on my laptop before they could be made available.

This might be a fanastic first Electron Application for me.
